# StackServe Plugin

Official plugin & remote MCP configuration for **StackServe** — a workload-aware cloud stack advisor with deterministic decimal pricing, compatibility validation, cited provider docs, and setup bundles.

- **Remote MCP Endpoint:** `https://mcp.stackserve.net/mcp`
- **Source Repository:** https://github.com/kztJames01/StackServe
- **Website:** https://stackserve.net
- **Support:** https://stackserve.net/support
- **Privacy:** https://stackserve.net/privacy
- **Terms:** https://stackserve.net/terms

## Install

### Claude Code
```text
/plugin marketplace add kztJames01/StackServe-plugin
/plugin install stackserve@stackserve-marketplace
```

### OpenAI Codex
```sh
codex plugin marketplace add kztJames01/StackServe-plugin
codex plugin add stackserve@stackserve-marketplace
```
